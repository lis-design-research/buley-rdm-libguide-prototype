# Research Data Management LibGuide-style prototype

Group 4, LIS 2024, Case Study 4. This is a **researcher-facing, interactive LibGuides-style prototype**, not a narrative of team meeting notes and not an official Springshare LibGuide.

## What it demonstrates
- Task-based Start Here page
- Funder requirements and DMP guidance
- Research data lifecycle support
- Interactive choice between self-service guidance and specialist assistance
- External RDM tools and a scenario for peer testing

## Test scenario
A faculty researcher preparing a grant must locate DMP guidance, determine where to find storage guidance, and identify what kind of support to seek for sharing data. Testers can navigate the guide without additional explanation.

## Important boundaries
This is a class prototype using Buley Library and SCSU as an institutional context. It is not an official library page, does not receive or transmit requests, and does not assert that proposed campus services, staffing, or referral responsibilities have been confirmed. No new RDM ambassador role is proposed.

## Deployment
Upload `index.html` to the root of the GitHub repository. For a public repository, enable GitHub Pages under **Settings → Pages → Deploy from a branch → main / (root)**. The published site is separate from the GitHub code view. Invite collaborators under repository access settings.
